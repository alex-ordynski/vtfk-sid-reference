# vtfk-sid — знімок `after-lab02`

Це знімок тієї ночі, коли ми посадили капсулу на дієту: у `core/sid/` лежить мій перший справжній вантаж — маленька програма, яка озивається одним рядком, а в `core/capsule/` поруч із протоколом розгортання ночі 1 стоять два креслення — `Dockerfile.naive`, «танк», що тягне за собою цілий тулчейн, і багатоетапний `Dockerfile`, який забирає в капсулу лише готовий бінарник. Збирай з кореня: `docker build -f core/capsule/Dockerfile -t sid-capsule core`, порівняй з «танком» — і побачиш, скільки зайвого ми скинули. Дієта ще не скінчена: порядок шарів, кеш і порожній `scratch` чекають на тебе. А наступної ночі капсулі знадобиться сусід — і спільна мова з ним.
